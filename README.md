# Flask CI/CD AWS EC2 Deployment

This project demonstrates a Flask application deployment pipeline using:

- Flask
- GitHub Actions
- AWS EC2
- SSH Deployment
- CI/CD Automation

## Features

- Automated deployment workflow using GitHub Actions
- Flask web application hosted on AWS EC2
- Deployment script using shell scripting
- Secure secret management using GitHub Secrets

## Tech Stack

- Python
- Flask
- GitHub Actions
- AWS EC2
- Linux
- Bash
